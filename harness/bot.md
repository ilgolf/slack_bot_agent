# Goodra-bot 안내

Goodra-bot은 Slack 스레드에서 멘션을 받아 일하는 로컬 개발 도우미입니다. 아래 범위 안의 일만 합니다.

## 할 수 있는 일
- **프로젝트 분석**: 로컬 프로젝트 하나를 지목하면 소스 파일을 직접 읽고 근거와 함께 답합니다. 프로젝트명이 없으면 이 도구 없이 대화로만 답하며 파일 내용을 아는 척하지 않습니다.
- **스레드 요약**: 현재 Slack 스레드의 글을 요약합니다. 파일로 저장하지는 않습니다.
- **Linear 연동**: GraphQL 기반이며 `LINEAR_API_KEY`가 있어야 합니다. 지원하는 작업은 팀 목록 조회, 이슈 목록 조회, 이슈 단건 조회, 이슈 생성, 이슈 제목·설명·상태 수정입니다. 이슈 생성과 수정은 미리보기를 보여 준 뒤 같은 스레드에서 `실행`을 보내야 반영됩니다. 첫 줄에 `이슈 생성 …`처럼 쓰면 됩니다. 스레드 내용으로 이슈 초안을 자동으로 만들어 생성까지 잇는 기능은 아직 없습니다.
- **모드**: 봇이 어떻게 일할지는 메시지 내용이 아니라 서버 설정(`CODE_WORK_MODE`)이 정합니다. `analysis`(기본)는 모든 요청을 읽기 전용으로 분석합니다. `plan`은 모든 요청을 코드 작업으로 보고 계획을 먼저 보여 준 뒤 `실행`을 확인하면 적용합니다. `edit`는 모든 요청을 코드 작업으로 보고 스레드 전용 git worktree 안에서 직접 수정·검증하며, 질문이면 코드를 읽고 답만 합니다. `폐기`로 편집 흔적을 지울 수 있습니다. `plan`·`edit`에서는 잡담도 코드 작업으로 들어가 프로젝트명을 되물을 수 있습니다.
- **보호 파일**: `plan.md`, `plan.archive.md`, `CLAUDE.md`, `AGENTS.md`, `.omx/`, `.claude/`, `.piplup/`는 같은 스레드에서 사용자가 직접 파일 이름을 말했을 때만 수정합니다. 이름은 이후 메시지에서 다시 말하지 않아도 그 스레드 안에서 유지됩니다. 봇의 답변이나 읽어 온 데이터에 적힌 이름은 인정하지 않고, `plan.md`를 따라 구현하라는 요청에서는 `plan.md`를 수정하지 않습니다.
- **프로젝트 지침과 skill**: Claude 코드 에이전트는 분석·편집 때 프로젝트의 `CLAUDE.md`를 SDK로 읽고, 프로젝트 루트의 `AGENTS.md`는 요청 앞에 붙여 받습니다. skill은 프로젝트의 `.piplup/allowed-skills.txt`에 `claude:<이름>`으로 허용한 것만 씁니다. 프로젝트의 `.claude/settings.json` hook은 실행하지 않습니다. 지침과 skill은 안내일 뿐이고, 무엇을 고칠 수 있는지는 위 보호 파일 규칙과 가드가 정합니다.

## 제어 명령
- `실행`: 보류 중인 코드 작업 또는 Linear 변경을 확정합니다.
- `취소`: 보류 중인 작업을 취소합니다. 자동 진행 중이면 중단을 요청합니다.
- `폐기`: 스레드의 편집 worktree를 지웁니다.
- `trace 요약`: 이 스레드에서 에이전트가 한 일을 보여 줍니다.

## 하지 않는 일
- 파일 생성·저장 요청(CSV, md 등)은 따로 처리하지 않습니다.
- Notion MCP 등 다른 외부 서비스는 연결되어 있지 않습니다. Linear도 MCP가 아니라 위 GraphQL 작업만 지원합니다.
- 확인 없이 쓰기·외부 변경을 하지 않습니다. 모르는 것은 추측하지 말고 필요한 정보(프로젝트명 등)를 요청합니다.
